# 字符串解密

D810G 检测并解密 OLLVM 加密的字符串，支持多种解密方法。

## 支持的方法

| 方法 | 描述 |
|------|------|
| 单字节 XOR | 尝试全部 256 个密钥 |
| 多字节 XOR | 通过频率分析恢复密钥 |
| 带索引的 XOR | `byte[i] ^= key ^ i` |
| RC4 | 流密码暴力破解 |
| ROT-N | 全部 255 种旋转 |
| 替换表 | 自定义 256 字节查找表 |

## 工作流程

1. **扫描** 各段（`.data`、`.rodata`）中的高熵区域
2. **尝试** 对每个候选区域应用所有解密方法
3. **评分** 根据可打印字符比率对结果打分
4. **排名** 返回得分最高的候选结果
